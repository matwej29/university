# Сервис для проверки заданий ЕГЭ.

### Описание фронтенда (флоу):
Проверяющий заходит на сайт под своим логином и выбирает задание для проверки. После проверки он ставит оценку и выбирает следующее задание.

### Описание структур:
Проверяющий:
номер (primary key, уникальный)
имя (фио)
предметы для проверки (например: математика, информатика)

Задания:
номер задания (pk, уникальный)
текст задания
ответ (правильный ответ, каждое задание имеет ответ)
предмет (по какому предмету задание)

Решения:
номер решающего (pk)
номер задания (pk)
текст решения
ответ
номер проверящего (null, назначается при проведении проверки)
оценка

Предмет:
название (pk))
